# Source images (not deployed)

Original, full-resolution client photos and unused alternates, moved out of
`public/` during the GEO audit fixes (Nov 2026). Files in `public/` ship with
every deployment and can be downloaded by anyone, so only the optimised images
the site actually references live there now.

To use one of these, export an optimised WebP (≈1600px wide, quality ~80) into
`public/images/…` and point the config at it.
